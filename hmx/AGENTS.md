# 独立した HMX の原文転記

- 唯一の原典は親フォルダの `main.pdf`。識別情報と範囲は `audit/source.json` にある。
- 既存 EHMX のコード・証明を import・再利用・変更しない。
- 今回の目標は原文の転記。数学的結果は `def ... : Prop` として記述し、証明・`axiom`・`sorry`・結論を仮定にした穴埋めを追加しない。
- ユーザーの指定に従い、原典の誤記候補を修正しない。未定義の記号は型を付けて引数にし、記号の読みや原文との対応を `audit/ambiguities.json` に残す。
- **転記の完了と、命題の成立性・解釈の妥当性の確認は別である。** 原文の問題を数学的に解決していなくても転記は完了できる。ただし、未収録の項目を原文の問題として隠さない。
- `scripts/check_audit.py --require-coverage --lean-checks` は収録と参照先・構文の検査。`--require-complete` は未修正の転記問題と全出現の個別照合を追加確認する。原典の条件を命題に接続しないまま、単に引数として置いて転記完了としない。
- 「原典との差異が全て解消」「全定理が成立」とは、この検査やビルドだけから報告しない。証明はステートメントの検討後に行う。
- 報告は対象の原典番号、今回の転記・確認、未証明事項、次の作業の順で簡潔に述べる。造語を使わない。
- PDF は対応表から生成し、対応する Lean ファイルのハッシュを載せる。PDF と Lean を同期する。
