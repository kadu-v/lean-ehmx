# 独立した HMX の仕様固定

- 唯一の原典は親フォルダの `main.pdf`。識別情報は `audit/source.json` にある。
- 既存 EHMX の `lean/`、`tex/ehmx/`、証明、仮定を import・転記・変更しない。
- 原典の第3・4章と必要な背景・付録を対象とする。具体的な第5章の応用は別作業。
- 数学的結果は `def ... : Prop` として記述する。仕様固定前にその結果を証明せず、`axiom`、`sorry`、結論を仮定に移した構造体で穴埋めしない。
- 原文の誤記候補を黙って直さない。`audit/ambiguities.json` に原文の位置、問題、採用案、判断を残す。
- `scripts/check_audit.py --require-complete` が成功し、番号の抽出検査とは別の二度目の原典照合も完了するまでは「全て」「確定」「差異なし」と報告しない。
- ビルド成功はステートメントの正しさや証明完了を意味しない。
- 報告は目標の原典番号、今回の定義・検証、残る前提と未完了事項、次の具体的作業の順で書く。造語を使わない。
- PDF は対応表と同じデータから生成し、検証した Lean ファイルのハッシュを掲載する。
